## Overall Impression

Confident, on-brand chrome with designed degraded states. Missing: the operator. The first screen shows a metaphor title, "0 active", PR numbers and one action that dead-ends; the only real action ("Load demo data") is the one place that can crash. Biggest opportunity: make the shell carry one live product signal (spend today or last flight).

## What's Working

1. Brand in precise details — one hand, survives 390 and 2560.
2. Degradation is designed — counts vanish when null; the banner keeps pages usable; macOS title-bar padding is server-rendered (verified 88 px shift, drag region).
3. The copy does the branding; clean active state; one h1 per page, every control named, no overflow at 390 px.

## Priority Issues

1. [P1] "Load demo data" is unguarded, silent, and crashes when the database is locked. `loadDemoAction` calls `getDb()` unprotected; no `error.tsx`; no pending/success state. Fix: disable with a visible reason when `shell.dbError`; add `app/(shell)/error.tsx`; pending + inline result; confirm before writing. Command: harden.
2. [P1] Dead-end CTAs in the built action slots. Home "+ Add a bird" → `/agents?new=1` opens nothing; Agents has the same label disabled but still glowing (`shadow-glow-soft` survives `disabled:`); Runs "New run" → Home with no composer. Fix: one state for both (caption or hide) and `disabled:shadow-none`. Command: clarify.
3. [P2] Home unnamed and "the nest" ambiguous. `/` activates nothing; 404 says "Back to the nest" (Home) while Memory's eyebrow is "The nest". Fix: Home nav item or `aria-current` on the logo; one meaning. Command: clarify.
4. [P2] Database banner tells, doesn't help. Path twice, process id, no remedy, pill denies anything runs. Fix: plain remedy + retry link, path once, pill "—" when down. Command: clarify.
5. [P3] Gutters and the phone header. Header/footer at 32/48 px vs content 72/178 px; sticky header wraps to three rows (155 px) at 390. Fix: `shell-container` on header/footer inner; static header below 768 px. Command: layout.
